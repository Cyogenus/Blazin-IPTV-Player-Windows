Portal setup

Load your authorized Stalker Portal on Windows

  1. Enter the exact address provided by your source in Portal URL. Preserve the port and path; a Stalker address may include /stalker_portal/c/, but use the address you were assigned.
  2. Enter the authorized MAC value in the MAC field. Do not substitute the network adapter address of your PC unless your source specifically assigned it.
  3. Enable Play in Internal VLC Player or choose an external player.
  4. Click Get Playlist and wait for categories to load.
  5. Open a Live category and test playback, then check Movies, Series and EPG where your portal supplies them.

Stalker Portal or STB MAC?

Both use portal-style access and may involve a MAC identity. The portal's expected path and device profile determine compatibility; the words alone do not identify interchangeable settings. Follow the login type and values supplied for your account. The STB MAC guide covers the related workflow and optional profile fields.

If access fails, first check the complete URL, assigned MAC and active authorization. Add custom user-agent or device values only when documented by your source. If categories load but listings are absent, check EPG coverage before changing the portal identity.

Stalker & MAC Portal on PC

Use Stalker Portal directly on Windows without an emulator

Some IPTV applications are designed primarily for phones, Android TV devices, or set-top boxes. BLAZIN is a Windows desktop application, so an authorized Stalker or MAC Portal source can be managed directly on a Windows PC without installing an Android emulator.

Portal systems can require a specific URL, MAC-style identity, request user agent, or device profile values. Enter only the values assigned to your authorized source, then save the profile for reuse.

  • Native Windows 10 and Windows 11 application
  • Portal URL and MAC-style account details
  • Custom request user agent when required by your source
  • Optional device and profile compatibility fields
  • Saved profiles for repeat use

Compatibility checks

Use advanced settings only when the source requires them

Begin with the basic portal profile. Add user-agent, device, version, or related compatibility fields only when your source documentation requires specific values.

  • Confirm the complete portal URL and path
  • Check that your account is active and authorized
  • Choose Stalker Portal or STB MAC rather than an unrelated login type
  • Test basic settings before adding optional compatibility fields
  • Remember that missing EPG or artwork can be a source-data issue
