Actual app capabilities

Core BLAZIN IPTV Player features

These capabilities are available in the current Windows desktop build and can be tested with your own compatible source.

M3U and M3U Plus support

Load a local M3U file or remote M3U URL, then organize legal user-provided streams into Live TV, Movies and Series areas where the playlist data supports those groups.

Xtream Codes API login

Use a server URL, username and password to load categorized Live, Movies and Series sections, including compatible EPG maps and media metadata from the provider API.

STB MAC and Stalker Portal

Connect with compatible portal URLs and MAC details, including Stalker Portal workflows for users who need a Windows alternative to set-top-box style access.

EPG guide support

Use provider guide data or compatible XMLTV-style EPG metadata to show schedule information, channel tooltips and program details where your source provides them.

Internal VLC and external player options

Use the redesigned VLC-based internal player with background loading and GPU-assisted playback where supported, or launch a compatible external media player when your Windows setup needs a separate playback path.

Profiles for repeat setups

Save and filter STB MAC, Stalker, Xtream, M3U URL, and local playlist-file profiles so the same IPTV source does not need to be re-entered each time.

Custom User-Agent controls

Set request User-Agent and playback User-Agent values for sources that require specific request headers or player behavior.

Favorites, search and categories

Use compact category lists, clear search, favorites, Live TV, Movies and Series tabs to move through large channel lists faster.

33 desktop theme presets

Choose from dark, medium and light desktop theme presets, including Blue Grey, Graphite Steel, Storm Blue, Deep Ocean, Nord Light and other color options.

Performance and stability

Built for large Windows IPTV playlists

Large playlist handling

  • Background loading with Qt worker threads and bounded request concurrency.
  • Fast mode for very large Live or ALL channel lists.
  • Chunked list painting to keep the interface responsive on big playlists.
  • Poster and logo cache handling to reduce repeated image work.

Source safety and limits

  • Player-only app: no IPTV channels, subscriptions or copyrighted streams are included.
  • User controls their own legal playlist, account, portal and playback setup.
  • Timeouts and request limits are used to avoid provider API hangs on large data sets.
  • Microsoft Store installation keeps download and trial access simple.

Advanced Stalker and portal controls

Advanced Stalker Portal settings for compatible sources

For users who need more than a basic MAC field, BLAZIN IPTV Player includes optional advanced Stalker fields. Leave these blank unless your provider requires specific STB profile values.

Device identity fields

Optional serial number, fake MAC for profile requests, STB model, STB revision, device ID and device ID2 fields.

Portal profile fields

Optional profile version, portal version, hardware version, hardware hash, signature and PHP session details.

Timezone and metrics

Optional timezone, metrics random value and custom metrics JSON for portals that require exact profile metadata.
