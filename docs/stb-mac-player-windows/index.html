STB MAC setup

Connect using your assigned portal details

  1. Enter the address supplied by your source in Portal URL, including its path and port.
  2. Enter the assigned MAC value in the MAC field.
  3. Enable Play in Internal VLC Player or choose an external player.
  4. Select Get Playlist and wait for the available categories.
  5. Test a Live channel, then inspect source-provided EPG, Movies and Series.

STB MAC and Stalker are related portal workflows, not two guarantees that the same values will work everywhere. Use the source's specified profile and path. For a Stalker-style address, see the Stalker setup steps.

Keep the original assigned values when troubleshooting. Advanced compatibility fields are for matching your authorized source, not obtaining access to a different account. Save a working connection through Profiles → Profile Manager so you can reuse it.

Portal workflow

Bring STB-style portal details into a Windows player

STB MAC workflows are different from normal M3U playlists. Instead of a playlist file or Xtream username and password, the setup commonly revolves around a portal URL and MAC-style details. BLAZIN provides a Windows profile path for that source type so users can test portal access without turning the whole workflow into a mobile or set-top-box experience.

The value of BLAZIN is in the compatibility controls and the PC browsing experience. When your source responds correctly, you can use the same Windows player tools around categories, search, favorites, guide data, logos, artwork, internal playback, and external player workflows.

  • Create a dedicated STB MAC profile for a legal portal source.
  • Enter portal and MAC-style details supplied by your source.
  • Use custom user agent and advanced compatibility options when needed.
  • Browse available Live TV, Movies, Series, categories, EPG, logos, and posters when supported.

Troubleshooting

What to check if a portal does not load

  • Confirm the portal URL includes the correct path and no extra spaces.
  • Check the MAC-style value and any portal-specific formatting requirements.
  • Try the request user agent or advanced fields your legitimate source specifies.
  • If Live TV loads but VOD does not, the portal may expose sections differently.
  • If artwork or EPG is missing, the source may not return compatible metadata.

FAQ

STB MAC player questions

Does BLAZIN IPTV Player provide STB MAC service?

No. BLAZIN does not provide portals, subscriptions, channels, playlists, or provider accounts. Users must provide their own legal IPTV source.

What details do I need for STB MAC setup?

You usually need the portal URL and MAC-style login details from your legal source. Some sources may also require specific user agent or compatibility values.

Why does BLAZIN include advanced STB fields?

Real portal setups can vary. Advanced fields help users test compatibility values their legitimate source requires.

Can STB MAC sources show EPG and posters?

They can only show EPG, logos, and artwork when the source provides compatible data.
